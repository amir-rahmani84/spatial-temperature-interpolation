## Corrected reproducible revision — 2026-11-27

The original project is preserved outside this proposed repository. No remote repository has been created. Original software is now MIT-licensed under the author's final instructions.

### Confirmed defects and corrections

- Corrected Kelvin conversion from subtraction of 272.15 to **273.15**, lowering reference temperatures by 1 °C. Percentage errors consequently change; raw-basis RBF need not preserve predictions under a temperature offset.
- Split RBF into Thin-Plate Spline kernel (`r² log r`) and Multiquadric kernel (`sqrt(1+(r/epsilon)²)`). Original maps used thin_plate while LOOCV used multiquadric. Both now pass through a single dispatcher and configuration in maps and folds. Retained SciPy `Rbf` with zero smoothing and its training-coordinate default epsilon; this is the original raw kernel expansion, without an affine polynomial tail. The original report's polynomial-tail TPS equation did not describe the implementation. No claim of the classical curvature-minimizing TPS is made.
- Replaced degree-space Euclidean distances with WGS84 / UTM zone 39N (EPSG:32639), in kilometres. Around 37.5°N, one longitude degree is approximately 0.79 times a latitude degree. Degree-space distance had a directional distortion. Grid display remains geographic; output spacing is not a new observational resolution.
- Retained spherical ordinary kriging with variance from training temperatures and zero nugget. The original fixed scale of 0.5 degrees is represented explicitly as a **55.5 km range** (a latitude-based approximation, not an exact equivalence under projection). No variogram optimization was added. This is a consequential scale assumption.
- Replaced Cholesky on the augmented kriging matrix with a symmetric indefinite solve. A rank/residual-checked least-squares fallback uses a relative singular-value cutoff of 1e-12; no diagonal jitter or hidden smoothing is added. Rank-deficient systems fail explicitly.
- IDW now handles exact-coordinate matches without a 1e-10 distance substitution; validates unique spatial locations and uses scaled positive weights. Its fixed -0.0065 °C/m lapse rate is retained, applied as interpolation of `T - lapse*height` then restoration at target height. Only IDW uses elevation, as in the original experiment.
- Matched target DEM by coordinates with explicit tolerance instead of assuming CSV row order matches the generated geographic grid.
- Replaced inconsistent array shapes, silent NaN omission and truncation with scalar fold predictions, explicit failures and invalidation of whole affected method-period aggregates. All five methods use identical folds.
- Retained equal-month 2015–2024 climatologies (annual, MAM, JJA, SON, pooled DJF). DJF is not a complete cross-year winter series. Day weighting and spatial block CV were not silently substituted.

### EBK audit and documented methodological extension

- Renamed the fifth configuration **EBK-inspired local kriging**. It does not reproduce commercial EBK's simulated-data refitting or Bayesian semivariogram weighting.
- Original Gaussian additive proposals were symmetric and its log-acceptance ratio was formally appropriate for the stated unnormalized target on constrained parameters. However, `exp(-sum variogram residual²)` was an unspecified pseudo-likelihood, not a Gaussian spatial data likelihood. Unbounded positive parameters give a potentially improper target (range can increase indefinitely with a finite limiting score). No prior, likelihood scale justification or convergence evidence was provided.
- Introduced explicit finite uniform bounds on nugget, partial sill and exponential scale (normal-score units², units² and km), retained the squared-residual pseudo-target with fixed scale 1, and reject proposals outside bounds. These make a proper bounded numerical target, **not a calibrated posterior**. Defaults are declared assumptions, not selected using LOOCV. Burn-in is 75 of 150 iterations and 30 retained draws are resampled with replacement. Such short chains do not establish convergence or effective sample size.
- Original code averaged variogram parameters then solved once. Nonlinearity means prediction at average parameters is not average prediction. Now each sampled model yields a local kriging prediction, inverse-transformed before averaging. This is a methodological extension, not just a solver correction.
- Fit normal scores to training values only with average ranks for ties; inverse transform uses corresponding unique scores and clamps outside the training temperature range. This yields a heuristic point estimate with tail clipping and nonlinear back-transformation bias; it is not a conditional expectation with bias correction.
- Removed unsupported predictive standard deviation: the original standard deviation of a one-element array was identically zero. Neither parameter spread nor model-prediction spread alone would account for full predictive uncertainty. No uncertainty surface is reported.
- Cache by unordered neighbor subset and use a NumPy SeedSequence derived from experiment/fold seed and neighbor indices. Identical neighborhoods share a reproducible chain; independent neighborhood seeds are scheduling-independent. Joblib worker count is explicit. This also makes full maps feasible.

### Evaluation and reporting

- Primary metrics are MAE, RMSE, NSE and Spearman. Historical MSE, MAPE, SMAPE and diagnostic Pearson are retained. Undefined metrics remain NaN; no artificial epsilon is added to Celsius denominators. SMAPE with absolute denominators is bounded by 200%, contrary to the original report's unbounded-range statement.
- TOPSIS retains oriented min–max normalization and Euclidean distances. Computes `0 log 0 = 0` exactly, gives constant criteria zero weight, supports negative NSE, and treats wholly tied alternatives equally. Removed the arbitrary 1e-8 offset. Exports criterion weights and three ranking configurations.
- Original criteria: MSE, MAE, MAPE, SMAPE, NSE. Primary ranking: MAE, RMSE, Spearman. Reduced sensitivity ranking: MAE, Spearman. NSE is reported but excluded from primary ranking since, within a period, it is an affine function of MSE. RMSE and MAE still overlap; the reduced configuration tests this choice. Entropy does not remove redundancy.
- Preserved original saved metric summaries as explicitly historical CSV records; never labeled them corrected results. Minimum individual errors are distinguished from mean absolute errors.
- Reorganized notebook into 13 sections with one helper module; removed stale outputs, repeated implementations and machine-specific paths. Added numerical/protocol tests and portable data acquisition instructions.
- Replaced unsupported broad superiority/novelty claims, weather-station terminology and commercial EBK descriptions. Revised report retains academic context, author and supervisor; original sources remain private. Bibliographic audit tracks every original reference and removes unverified support from the revised text rather than guessing metadata.
